How a zone picks its icon

Matching runs on the model name the player already reports.

Where the name comes from

The bridge already reads each player's modelName from its device description and puts it in the renderer it publishes. That string is all the matching needs.

Matching

Lower-case the name, strip Sonos, then test the keys under each glyph in order, longest first — so one sl never gets caught by one.

Nothing matches

New hardware, a SYMFONISK, or a player that never answered its description falls back to the cone-and-waves glyph. A zone is never left without an icon.

Getting them to Audirvana

UPnP wants PNG in iconList, so these get rasterised per model at 48 px and 120 px and served from /dev/{uuid}/icon/{size}.png — the route that exists today.
