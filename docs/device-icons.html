How they are made and matched

Generated from device dimensions, keyed on the model name the player reports.

One projection

Each device is described in centimetres — width, depth, height — and projected with depth receding up and left at 0.38 scale. Nothing is drawn by hand, so the whole set shares a horizon.

Where the name comes from

The bridge already reads each player's modelName from its device description. Lower-case it, strip Sonos, then test the keys under each glyph longest-first, so one sl is never caught by one.

Nothing matches

New hardware, a SYMFONISK, or a player that never answered its description gets the plain cabinet with a driver. A zone is never left without an icon.

Getting them to Audirvana

UPnP wants PNG in iconList, so these get rasterised per model at 48 px and 120 px behind /dev/{uuid}/icon/{size}.png, the route that exists today.

At 48 px the line work holds. Below about 24 px a hairline starts to break up, so the stroke wants to sit near the top of the slider for the small size.
